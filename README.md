# portfolio_bk2 — Bharath Kumar P.V

Interactive 3D particle hero portfolio featuring custom Three.js WebGL dots animation, reveal transitions, dynamic project showcase, tech stack universe, interactive journey timeline, and smooth scroll effects.

## 🚀 Live Links
- **Live Website (Vercel)**: [https://portfoliobk2.vercel.app](https://portfoliobk2.vercel.app)
- **GitHub Repository**: [https://github.com/BharathKumarPV/portfolio_bk2](https://github.com/BharathKumarPV/portfolio_bk2)

## 🛠️ Features & Stack
- **Three.js & Custom WebGL Shaders**: Interactive particle cloud hero (`dots.bin`) with camera choreography and responsive lighting.
- **Pure Static Architecture**: Fast load times, zero-latency rendering, responsive mobile & desktop layout.
- **Visual Effects**: Particle embers, 3D tilt interactions, magnetic buttons, dynamic journey timeline, and ambient glow.
- **Key Sections**:
  - 3D Particle Cloud Hero with "Reveal" action
  - 01 // About
  - 02 // What I Build
  - 03 // Beyond the Code
  - 04 // Tech Universe
  - 05 // A Journey Through Code (Interactive Timeline)
  - 06 // Projects Showcase
  - Connect & Social Links

## 📁 Project Structure
- `index.html` — Main HTML page with embedded styling, UI overlays, and interaction controllers.
- `hero.js` — Three.js WebGL canvas rendering engine and particle controller.
- `dots.bin` — Binary point cloud data for 3D dot matrix representation.
- `photo-cutout.webp` — Optimized transparent portrait asset.
